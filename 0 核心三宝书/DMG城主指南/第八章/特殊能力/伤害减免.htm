伤害减免

伤害减免（Damage Reduction）

一枝箭贯穿了吸血鬼的肩膀，但她毫不在意地拔出箭来，你可以看见她身上的伤口瞬间愈合。“你还太嫩了！”她肆无忌惮地笑着。

有些魔法生物拥有能够瞬间医疗伤害或无视对方攻击的超自然能力，也就是伤害减免。

伤害减免能力在标示时分为两部分，前面的数字代表能够吸收一般攻击的伤害点数。例如：伤害减免5点的生物若受到一般攻击造成8点伤害，会吸收5点，只承受3点伤害。

一般来说，某种特定武器能够克服特定生物的伤害减免能力。这通常会标示在该生物伤害减免说明的斜线后方。例如：狼人的伤害减免是“10 / 银”，表示狼人对于正常武器造成的伤害，每次都可吸收10点，但他无法吸收炼银武器造成的伤害。有些伤害减免能力只有魔法武器可以克服（具有+1或更高增强加值的武器，精制武器加值不计），有些则需要特定伤害形态才能击穿（挥砍或敲击），有些则是特定阵营的武器才能克服（具有神圣能力或受到“阵营武器”影响的武器）。若在斜线后方是一条横线（例如野蛮人职业特性中的伤害减免），则表示该生物除了使伤害减免无效的特殊攻击之外，能够吸收所有攻击方式造成的伤害。

若射击武器本身有+1或更高的增强加值，对抗伤害减免时，射出的弹药也视同魔法武器。举例来说，+1投石索射出的弹丸视同魔法武器。同样地，若射击武器本身属于特定阵营，例如：+1神圣长弓或受到“阵营武器”影响的武器，射出的弹药也具有阵营特性，而且可以跟弹药本身的阵营累计。举例来说，+2混沌短弓射出的+1邪恶箭就会具有同时具有混乱与邪恶阵营，前者来自于射击武器，后者来自弹药本身。

当伤害减免能力完全吸收攻击伤害时，该次攻击所附带的任何特殊效果也完全无效（例如：伤口类型的毒素、伤口类型的疾病、武僧的震慑破等效果）。但是伤害减免能力无法免除触碰攻击、附加在攻击上的能量伤害（如火元素所造成的火焰伤害）以及能量吸取所造成的伤害。经由呼吸、食用、接触而传播的毒素或疾病，也不会被伤害减免所吸收。若施法时遭到攻击，但所有伤害值都被伤害减免能力吸收，便不会干扰法术。

伤害减免无法吸收法术、类法术能力与能量伤害（即使是一般火焰）。

伤害减免能力有时是因为该生物能瞬间医疗自己，例如：用长剑在恶魔身上划开一道口，伤口会随即愈合。有些伤害减免能力则是因为该生物皮粗肉厚，例如：石像鬼或铁魔像。在这些情形中，攻击者都能明显察觉正常攻击方式对敌人无效。

若生物同时具有多种不同的伤害减免能力，这些能力会并存，但只取较高者，不能累加。举例来说，熊人天生具有伤害减免10 / 银，若再受到“正气如虹”法术影响，会获得伤害减免5 / 邪恶。因此，当熊人受到非银制也非邪恶的武器攻击时，每次可以吸收10点伤害。受到银制非邪恶武器攻击时，伤害减免10 / 银会被克服，但5 / 邪恶仍有作用，因此每次可以吸收5点伤害。受到非银制邪恶武器攻击时，伤害减免5 / 邪恶会被克服，但10 / 银仍有作用。唯有受到银制邪恶武器攻击时，才无法吸收任何伤害。
